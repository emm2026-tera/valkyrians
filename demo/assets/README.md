# Assets

Drop your visuals here, keeping the file names referenced in `data/*.json`
(or edit the `image` paths there). Missing images fall back to an emoji.

- `branding/logo.png` - logo (optional, shown in header)
- `characters/` - one PNG per character (suggested 512x512, transparent)
- `businesses/` - one PNG per shop (suggested 640x400)
- `accessories/` - one PNG per accessory (suggested 256x256, transparent)
